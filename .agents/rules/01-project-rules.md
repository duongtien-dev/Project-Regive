# ReGive Project Rules

## Stack
- Next.js
- TypeScript
- Axios
- Tailwind CSS
- Ant Design
- Zustand khi cần
- Lucide Icons nếu phù hợp

## Bắt buộc
Trước khi làm task phải đọc:
- `USER_WEBSITE_PLAN.md`
- code hiện tại liên quan
- backend API liên quan nếu task có gọi API

## Nguyên tắc
- Không tự bịa API.
- Không tự đổi architecture.
- Ưu tiên reuse component, hook, service, type đã có.
- Không sửa file không liên quan.
- Không dùng `any` nếu không cần.
- Không hardcode dữ liệu production.
